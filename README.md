# Google Earth Engine Remote Sensing Experiments

This repository contains selected workflows developed while learning and testing satellite image preprocessing and remote sensing methods in Google Earth Engine.

## Objectives

- Explore satellite image preprocessing and masking.
- Calculate and evaluate spectral indices.
- Test approaches for water detection.
- Develop reproducible geospatial analysis workflows.

## Tools and Technologies

- Google Earth Engine
- JavaScript
- Multispectral satellite imagery
- Remote sensing and GIS

## Repository Contents

The scripts are organized by methodological task.
Each script includes comments describing its purpose,
input data, processing steps, and limitations.

## Status

Exploratory and testing versions. These scripts are
not final or validated research products.

## Data and Reproducibility

Data sources, spatial and temporal coverage, and any
required assets are documented where applicable.
Access to external datasets or Earth Engine assets may
be required to reproduce individual experiments.

## Research Integrity

This repository contains selected material suitable
for public sharing. Unpublished final algorithms,
restricted data, and results not approved for release
are excluded.
